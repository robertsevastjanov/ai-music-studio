# AI Music Studio

An AI-assisted music production project focused on creating original music inspired by research into Billboard Hot 100 hits, contemporary genres, and music production techniques.

## Goals

- Produce the first original, high-quality release.
- Learn music theory, songwriting, arrangement, and audio engineering through practice.
- Combine AI-assisted creativity with human artistic decisions.
- Apply Rick Rubin-inspired minimalism and senior software engineering principles.
- Build a repeatable, documented production pipeline after validating the first release.

## Principles

1. Quality over quantity.
2. Every musical element must serve a purpose.
3. Human approval for important creative decisions.
4. Small, testable, documented steps.
5. Preserve original files and project history.
6. Respect copyright, licenses, and originality.
